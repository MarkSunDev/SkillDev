## 4. 任务生成规则

1. `ports-inventory` 里的每个 Fake/NoOp/Local → 一个 adapter 任务。
2. `deferred` 每项 → 一个任务（owner/风险/验收/依赖）。
3. 平台缺口 → channel/adapter 任务。
4. 埋点缺口 → 对账任务。
5. 历史 bug 根因涉及 SDK → 回归测试。
6. 业务补齐（如礼物/CE/恋爱铃/Visitor VIP）→ 垂直切片，不是“只接 SDK”。
7. 每个任务有测试 ID/验收/证据。
